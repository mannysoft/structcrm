# Ideal Customer Profile

## Primary ICP
Small and medium construction companies with:
- 5–50 employees
- Multiple active projects
- A project manager or site supervisor
- Recurring construction work
- Existing administrative processes
- Willingness to use cloud software

## Best Segments
1. General contractors
2. Residential builders
3. Renovation contractors
4. Commercial fit-out contractors

## Buying Signals
Prioritize companies that:
- Manage 3+ active projects
- Use spreadsheets heavily
- Use chat apps for coordination
- Have multiple site workers
- Need recurring client reporting
- Struggle with project costs
- Recently won several projects
- Are hiring project managers
- Complain about administrative workload

## Poor Initial Fit
Avoid companies that:
- Run only one project at a time
- Have no recurring projects
- Need highly specialized enterprise functionality
- Already have deeply integrated enterprise software
- Are unwilling to pay for software

## Buyer Personas
### Owner
Cares about profitability, visibility, cost control, simplicity, and ROI.

### Project Manager
Cares about tasks, deadlines, daily reports, documents, and team coordination.

### Site Supervisor / Foreman
Cares about easy mobile reporting, photos, workers, materials, and issues.

### Accountant
Cares about expenses, invoices, receipts, and financial accuracy.

## Qualification Questions
1. How many active projects do you manage?
2. How many people work on projects?
3. How do you track project expenses?
4. How do site teams submit daily reports?
5. How do you store project photos?
6. What software do you use?
7. What is the most frustrating administrative task?
8. How often do projects exceed budget?
9. Who makes software purchasing decisions?
10. What would make you switch from your current process?
