# ConstructFlow Demo Script

## Goal
Show how ConstructFlow solves the customer's specific problems without overwhelming them.

## Duration
15–20 minutes.

## 1. Dashboard — 2 minutes
Show active projects, project status, costs, recent activity, and upcoming tasks.

Ask:
"Would having this information in one place be useful to you?"

## 2. Project — 3 minutes
Show client, project details, budget, timeline, team, and progress.

## 3. Daily Report — 3 minutes
Show work completed, workers, materials, issues, and photos.

## 4. Tasks — 2 minutes
Show assigned person, due date, priority, and status.

## 5. Expenses — 3 minutes
Show expense, category, amount, receipt, and project cost summary.

## 6. Client Updates — 2 minutes
Show project progress, photos, documents, and updates.

## 7. Close — 3 minutes
Ask:
"Which part of this would be most useful to your company?"

Then:
"Is there anything important missing?"

If interest is strong:
"I'd like to set your company up for a 30-day pilot. Would you like to try it with one of your active projects?"

## Rule
Only demonstrate features connected to problems the customer actually described.
