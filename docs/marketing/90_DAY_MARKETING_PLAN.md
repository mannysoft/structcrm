# 90-Day Marketing Plan

## Days 1–14: Foundation
- Define the ideal customer profile
- Select the initial construction niche
- Interview at least 10 contractors
- Document current workflows
- Identify the top three painful problems
- Draft positioning
- Launch a simple landing page
- Create a realistic demo account
- Prepare a 15-minute demo
- Build the prospect tracker
- Build the first 100-company prospect list

## Days 15–30: Discovery and Outreach
Targets:
- 100 prospects
- 50 conversations
- 10–15 demos

Activities:
- Contact 20 prospects per weekday
- Ask workflow questions before pitching
- Record objections
- Identify current software
- Ask what the problem costs
- Ask what they would pay for a solution

## Days 31–45: MVP Validation
- Prioritize features from interviews
- Fix onboarding friction
- Prepare a reliable demo
- Invite 10–20 companies into a pilot
- Track activation

Activation events:
- Company created
- First client created
- First project created
- First daily report submitted
- First expense recorded
- First photo uploaded

## Days 46–60: Beta
- Run 30-day pilots
- Conduct weekly customer calls
- Measure usage
- Collect testimonials
- Identify must-have features
- Remove unnecessary complexity

Goal: at least 10 active pilot companies.

## Days 61–75: Paid Conversion
- Present pricing to active pilots
- Offer founding-customer pricing
- Schedule conversion calls
- Ask directly for payment
- Record objections
- Improve onboarding

Goal: first 3–5 paying companies.

## Days 76–90: Scale
- Increase outreach volume
- Launch referrals
- Publish customer stories
- Improve the landing page
- Focus on the highest-converting channel
- Continue demos every week

Goal: 10 paying companies.

## Weekly Rhythm
Monday: prospect research
Tuesday: outreach
Wednesday: demos
Thursday: follow-ups
Friday: customer interviews/onboarding
Saturday: content
Sunday: metrics review
