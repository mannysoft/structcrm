# ConstructFlow Sales Pipeline

## Stages
1. Prospect
2. Contacted
3. Responded
4. Discovery
5. Demo
6. Pilot
7. Negotiation
8. Won
9. Lost

## Required Fields
- Company
- Contact
- Email
- Phone
- Location
- Company size
- Construction type
- Active projects
- Current software
- Main pain
- Lead source
- Last contact
- Next action
- Stage
- Expected value
- Reason lost

## Weekly Targets
- 100 prospects researched
- 50 outreach messages
- 10+ conversations
- 5 demos
- 2–3 new pilots

Adjust targets based on actual conversion rates.

## Follow-up
Initial outreach:
- Follow-up 1: 2–3 days
- Follow-up 2: 4–5 days later
- Final follow-up: 5–7 days later

After demo:
- Follow-up within 24 hours
- Follow-up after 3–4 days
- Follow-up after 7 days

## Lost Reasons
Record the actual reason:
- Too expensive
- No need
- Wrong timing
- Existing software
- Missing feature
- No decision maker
- No response
- Not enough projects
