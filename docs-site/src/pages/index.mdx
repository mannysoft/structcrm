<h2 className="home-section-title">What is inside</h2>

| Capability | What you get |
| :--- | :--- |
| **Company and team** | Single database multi-tenancy with `company_id` scoping, staff invitations and seven staff roles. |
| **CRM** | Clients, a lead pipeline and supplier records. |
| **Projects and field** | Projects, tasks, daily logs, site photos, documents, time tracking, equipment and maintenance logs. |
| **Commercial and finance** | Contracts, cost codes, BOQ (with Excel import), budgets, progress reports, progress billings and payments, invoices, expenses, change orders and purchase orders. |
| **Client portal** | A separate external login where clients track progress, approve change orders and settle invoices. |
| **AI assistant** | A conversational agent that can read and change company data, with human approval for risky actions. |
| **REST API** | Sanctum token authentication and JSON endpoints for every module. |
